## 批次 A

### 1. SSH 主机指纹校验
- 文件：`server/internal/proxy/hostkey.go`、`hostkey_test.go`；`dialTarget` 改用回调；
  资产字段 `ssh_host_key_fp` / `ssh_host_key_policy`（迁移 `0031_*.sql`）；
  `OpsCredential` / `managerclient.Credential` 下发指纹；TOFU 回写
  `POST /internal/v1/ops/hostkey-learn`。
- 策略：`strict` / `tofu`（默认）/ `insecure`；环境变量 `BASTION_HOSTKEY_POLICY`。
- 验证：`cd server && go test ./internal/proxy/ -run HostKey`。

### 2. /internal 网络层隔离
- 文件：`manager/internal/api/netisolate.go`；`InternalConfig.TrustedCIDRs`；
  `BASTION_INTERNAL_TRUSTED_CIDRS`（默认 `127.0.0.0/8,::1/128`）。
- 验证：`go test ./internal/api/ -run Trusted`；用非受信源访问 `/internal/v1/*` 应 403。

### 3. WebSSH Origin 校验
- 文件：`server/internal/proxy/origin.go`；`BASTION_WEBSSH_ORIGINS` 白名单；
  空列表拒绝带 Origin 的浏览器请求；无 Origin（非浏览器）放行。
- 验证：`go test ./internal/proxy/ -run Origin`。

### 4. 口令到期强制拦截
- `Authenticate` / `AuthenticateByToken`（运维入口）拒绝过期/强制改密；
  Web `requireAuth` 链式 `requirePasswordCurrent`，白名单：改密/登出/me/refresh。
- 验证：设 `password_expire_days` 并回拨 `password_update_time`，登录后调业务 API 应 `AUTH_4008`；
  `POST /api/v1/auth/password` 仍可用。

### 5. 会话强制中断
- 代理：`livesession.go` 登记在途会话；`POST /internal/v1/sessions/{id}/kill`（HMAC）。
- 管理：`SessionKiller` + `POST /api/v1/ops/sessions/{id}/kill`（`ops:session:kill`）；
  迁移授予 sec/sys/super_admin。
- 验证：建会话后带权限调用 kill API；代理侧连接应断开，库状态 `terminated`。
- 边界：代理不可达时仍更新库状态；依赖节点心跳上报的 `address`。
