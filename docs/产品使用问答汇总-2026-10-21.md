## 1. 产品是什么 / 架构

**堡垒机**是运维准入与审计网关：运维人员不直连目标主机，而是经堡垒机完成身份认证、授权校验、协议代理、命令管控与会话录像。

### 逻辑分层

| 组件 | 职责 | 默认端口 |
| --- | --- | --- |
| **manager（管理服务）** | 初始化、认证、用户角色、资产账号、策略、工单、访问授权、审计查询、Web 控制台托管 | `:8080` |
| **server（服务端 / 代理）** | SSH 网关、WebSSH、命令管控、会话编排、录像封存；经 HMAC-SM3 回源管理面 | `:8081`（观测/WebSSH）、`:2222`（SSH 网关） |
| **PostgreSQL** | 业务库；生产仅监听本机 | `:5432`（建议仅 `127.0.0.1`） |
| **Web 客户端** | Vue 3 控制台（由 manager 托管静态资源） | 同 8080 |
| **桌面客户端** | Wails v2（Windows 优先；麒麟 Linux 后续） | 连管理面 API |

### 关键设计

- **服务端不直连数据库**：口令散列与资产凭据密钥只在管理面；代理可放 DMZ 横向扩展，本地主要持有录像加密密钥。
- **三权分立 + 运维/审批**：超管只做「管理员的管理者」；日常业务由系统/安全/审计三员与运维、审批人协作。
- **授权两层**：`binding`（长期绑定）与 `pass`（工单审批通行证），可表达「绑了但使用仍要审批」。

源码布局：`src/manager`、`src/server`、`src/client`、`src/shared`、`src/deploy`。

## 2. 角色及区别

内置 6 个角色（权限点数为运行库核对口径，会随迁移微调）：

| 角色 | 代码 | 主要做什么 | 明确不做 |
| --- | --- | --- | --- |
| 超级管理员 | `super_admin` | 创建/管理管理员账号、授角色、看系统配置；初始化后可封存 | **不做**资产、授权、策略、审计、运维等业务 |
| 系统管理员 | `sys_admin` | 用户/组织、资产与账号、设备运维（网络/集群）、**访问授权** | 不做审计、安全策略、密钥；**不能看明文口令** |
| 安全管理员 | `sec_admin` | 授权与策略、密钥、角色权限、准入；可看明文口令（高敏留痕） | 不做用户管理、审计；系统配置多为只读 |
| 审计管理员 | `audit_admin` | 审计查询、录像回放、报表、取证导出 | 不做任何管理与授权 |
| 运维人员 | `operator` | 对自己**已绑定**的资产发起会话/传文件；可提交工单 | 不看全量资产台账；无管理/审计 |
| 审批人 | `approver` | 工单审批、紧急放行、查看全部工单 | 无管理与审计 |

### 容易混淆的点

- **超管 ≠ 全能运维**：收敛后只管理「谁是管理员」，日常连机、批单、审录像都不靠超管。
- **系统管理员 vs 安全管理员**：录入资产与分配资源可由 sys/sec 协作（sys 也有访问授权能力）；看明文口令只归安全侧。
- **运维看不到未绑定资源**：正确入口是「我可访问的资产」（`/api/v1/ops/assets`），而不是资产台账。

## 3. 使用流程（管理准备 → 运维连机 → 工单审批 → 审计）

### 3.1 管理准备（管理员）

1. 初始化：设备命名 → 创建超级管理员 →（推荐）超管登录后创建三员；或向导一次性建三员后封存超管。
2. 系统/安全管理员：录入**资产**与**账号**（托管或不托管）。
3. 安全/系统管理员：在「访问授权」给运维做 **binding**；按需打开 `require_approval`。
4. 安全管理员：配置命令策略、口令/准入策略等。
5. 创建运维人员、审批人账号并赋角色。

### 3.2 运维连机

1. 运维登录 Web（或桌面客户端）。
2. 在「可访问资产」中选目标；若标记需审批，先走工单。
3. 经堡垒机建立会话（WebSSH / SSH 网关 `:2222` 等）。
4. **托管账号**：网关代填凭据，运维免密进目标。
5. **不托管账号**：连接时现场输入口令/密钥（不回显、不落库、不进录像）。

### 3.3 工单审批

闭环：**申请 → 审批通过自动生成 `pass` → 到期失效 / 可撤销**。

- 运维对「需审批」的绑定提交工单。
- 审批人通过：生成有时效的通行证；驳回须填意见。
- 申请人可在**待审批**时撤销本人工单。
- 紧急放行（持 `ticket:emergency`）：可先授权后补单（`supplement`）。

### 3.4 审计

- 审计管理员查操作日志、命令记录、告警、会话录像回放与取证导出。
- 高危/阻断命令可落 `audit_alert`（当前以入库为主，外发通知仍可增强）。

## 4. 授权与凭据

### 4.1 托管 / 不托管（账号级）

| 模式 | 凭据在哪 | 运维怎么用 |
| --- | --- | --- |
| `managed`（默认） | 堡垒机 SM4 加密托管 | 授权后网关代登，免密 |
| `manual` | **堡垒机不留存凭据** | 连机时现场输入；失败次数/超时受控 |

- 同一资产可混用不同模式；创建后可切换，但切回托管**必须同时提供凭据**。
- 系统管理员能改账号但不能看明文；看明文归安全管理员且写审计。

### 4.2 绑定 vs 通行证

| 类型 | 含义 | 谁产生 |
| --- | --- | --- |
| `binding` | 长期：可以访问或可以申请哪些资源 | 管理员在「访问授权」配置 |
| `pass` | 这一次审批是否在有效期内 | 工单审批通过自动生成 |

`require_approval=false`：绑定即可直连；`true`：绑定只表示可申请，必须有有效 `pass` 才能用。

判定顺序（简述）：有效 pass → 免审批 binding → 需审批 binding（提示申请）→ 无授权。

### 4.3 管理员不必代连

管理员负责配置资产、账号与授权；**日常连机由运维经堡垒机完成**。托管模式下凭据由网关使用，无需管理员替运维登录目标机。

## 5. 审批：是否人人同单、一票定音、如何避免卡住

### 现状实现口径（代码行为）

- **不是「人人会签」**：任一持有 `ticket:approve` 的审批人对**待审批**工单执行通过/驳回即可结束该单。
- **一票定音**：一次 `approve` 即将工单置为已通过并生成授权；一次 `reject` 即驳回。
- 多人审批人共享同一待办池；**先处理者生效**，无需全体点赞。

（库表预留了 `wf_approval_flow`、多节点、超时动作等字段，当前业务路径是单节点「审批」即时完结。）

### 如何避免工单卡住

1. **配多个审批人**（同一角色多人值班），避免单点请假。
2. **例行资源用免审批 binding**，只对高敏资源开 `require_approval`。
3. **紧急放行**：持紧急权限者可先通后补单（需制度约束）。
4. **申请人撤销**：待审批单可自行取消，避免僵尸单占着。
5. **审批人驳回要写意见**，减少来回猜原因。
6. 流程表支持超时动作（notify / auto_approve / auto_reject）——以实际部署是否启用定时任务为准；未启用时仍靠人工值班。

## 6. 网页上线步骤摘要

参考 `src/deploy/README.md`（真机实测）：

1. **准备构件**：交叉编译 `manager` / `server` / `migrate`；构建前端 `client/web/dist`。
2. **拷贝到目标机**（示例目录 `/opt/bastion`）：二进制、`deploy/`、前端 dist。
3. **执行** `deploy/install.sh`：PostgreSQL（容器）、库初始化、systemd 单元。
4. 浏览器访问 `http://<服务器IP>:8080`，走**初始化向导**。
5. 端口：`8080` 管理台；`8081` WebSSH/录像；`2222` SSH 网关；库仅本机。
6. **升级注意**：先停 server 再停 manager；启动相反。迁移 `migrate up` 放在重启前。前端热更新建议先清空 dist 再解压。
7. 更推荐 Nginx 同源反代（`/api`→管理、`/records`→服务端），减少跨域坑。

## 7. 2026-10-21 计划落地摘要

详见 `src/NOTES-2026-10-21.md`（张伟计划 11 项本机落地）。**未做真机 SSH/RDP/Oracle 端到端联调**，以编译与单测为主。

### 安全项（批次 A）

1. SSH 主机指纹校验（strict / tofu 默认 / insecure）
2. `/internal` TrustedCIDRs 网络隔离
3. WebSSH Origin 白名单
4. 口令到期 / 强制改密拦截运维与业务 API
5. 在途会话强制中断（kill API）

### 增强（批次 B）

6. 桌面客户端：短信 MFA、强制改密、证书临期提示  
7. 高危命令告警入库与查询  
8. UKey 临期列表与登录 hint；过期拒绝  
9. 短信验证码清理循环

### 协议骨架（批次 C）

10. RDP/VNC 骨架（默认关闭，无完整解析/授权/录像）  
11. Oracle 骨架（默认关闭，无 TNS/SQL 审计）

仍待增强示例：审计防篡改哈希链、外发通知、解释器内命令拦截边界说明等（见 `src/TODO.md`）。
